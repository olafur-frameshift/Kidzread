TO GET THE APP RUNNING (one-time setup)
----------------------------------------
[ ] Install Flutter SDK on your machine
      https://docs.flutter.dev/get-started/install/windows/mobile

[ ] Install Android Studio (includes emulator + SDK + adb)
      https://developer.android.com/studio

[ ] Clone the repo
      git clone <repo-url>
      cd Kidzread
      git checkout claude/kidsread-project-setup-65fsA

[ ] Generate the Android project shell (one-time, creates android/ folder)
      flutter create . --project-name kidsread --org com.kidsread

[ ] Install Dart dependencies
      flutter pub get

[ ] Add fonts to assets/fonts/
      Download Fredoka from https://fonts.google.com/specimen/Fredoka
      Place Fredoka-Regular.ttf and Fredoka-Bold.ttf in assets/fonts/

[ ] Run on emulator or phone
      flutter run
