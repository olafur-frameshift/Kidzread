# Fonts

Place font files here:

- `Fredoka-Regular.ttf`
- `Fredoka-Bold.ttf`

## Download

Fredoka is available from Google Fonts (SIL Open Font License):
https://fonts.google.com/specimen/Fredoka

Download → extract → place the two weights above in this directory.

## Fallback

Until fonts are added, Flutter will use the system default sans-serif.
The `pubspec.yaml` already declares the `Fredoka` font family.
